# Web1: موقع عيادة د. رشا رشاد

موقع عيادة د. رشا رشاد اللاوندي لطب الفم والأسنان في أرض العزب، بورسعيد.

## المميزات
- تصميم زجاجي (Glassmorphism) فوق خلفية بتدرجات ألوان متحركة
- 3 صفحات بإحساس تطبيق (الرئيسية، الخدمات، الحجز) مع انتقالات ناعمة
- شريط تنقل سفلي على الموبايل
- حجز عن طريق رسالة واتساب جاهزة بالعربي
- عربي RTL، ومعمول للموبايل أولاً
- SEO محلي (Schema.org Dentist)، وإمكانية وصول، ودعم تقليل الحركة

## التشغيل
ملف واحد `index.html` من غير أي build. افتحه في المتصفح أو فعّل GitHub Pages على فرع `main`.
